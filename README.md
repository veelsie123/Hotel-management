
# Demo Spring Boot Application

This project was generated by the assistant (Spring Initializr style) with sensible defaults.


Requirements

- Java 17 (or the `java.version` set in `pom.xml`)
- Maven 3.6+ (or use the Maven Wrapper)

Run locally:

```bash
# using installed Maven
mvn spring-boot:run

# or using the Maven Wrapper (generate wrapper jar first if missing)
./mvnw spring-boot:run
```

Build jar:

```bash
mvn -DskipTests package
java -jar target/demo-0.0.1-SNAPSHOT.jar
```

Generating the Maven Wrapper (if you want the wrapper files to work locally):

```bash
mvn -N io.takari:maven:wrapper
```

The app exposes a simple endpoint at `/`.

Database

This project uses MySQL. You can run a local MySQL instance with Docker Compose:

```bash
docker compose up -d
```

Default datasource settings (in `src/main/resources/application.properties`):

- URL: `jdbc:mysql://localhost:3306/dg_hotel`
- username: `demo`
- password: `demo`

After starting MySQL, run the app as described above. The application will create/update tables automatically (`spring.jpa.hibernate.ddl-auto=update`).

Database schema (entities created):

- `User` (`users`): application users (username, password, role)
- `Customer`: hotel customers
- `Room`: rooms with number, type, price
- `Reservation`: links `Customer` and `Room`, includes check-in/check-out
- `Payment`: one-to-one with `Reservation`

Relationships:

- Customer 1..* Reservations
- Room 1..* Reservations
- Reservation 1..1 Payment

Flyway migrations

The project now uses Flyway for schema migrations. The initial migration is in `src/main/resources/db/migration/V1__init.sql`.

API endpoints (examples):

- `GET /api/rooms` — list rooms
- `POST /api/rooms` — create room
- `GET /api/reservations` — list reservations
- `POST /api/reservations` — create reservation (send `customerId`, `roomId`, `checkIn`, `checkOut`)
